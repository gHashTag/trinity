## Deployment Scripts

### deploy-gh-pages-quick.sh

Quick deployment using existing builds (recommended for most updates).

**Process:**
1. Backup existing gh-pages branch
2. Verify website/dist/ and docsite/build/ exist
3. Create status.html
4. Assemble deployment bundle
5. Force push to gh-pages

**Usage:**
```bash
./bin/deploy-gh-pages-quick.sh
```

### deploy-gh-pages.sh

Full deployment including rebuilds (use when dependencies change).

**Process:**
1. Backup existing gh-pages branch
2. Run `npm install` and `npm run build` for website
3. Run `npm install` and `npm run build` for docsite
4. Create status.html
5. Assemble deployment bundle
6. Force push to gh-pages

**Usage:**
```bash
./bin/deploy-gh-pages.sh
```

### monitor-dashboard.sh

Health monitoring script for automated checks.

**Checks:**
- Main URL: https://gHashTag.github.io/trinity/
- Status page: https://gHashTag.github.io/trinity/status.html
- Documentation: https://gHashTag.github.io/trinity/docs/

**Thresholds:**
- HTTP status: 200
- Response time: < 5 seconds
- Max consecutive failures: 3

**Usage:**
```bash
# Run once
./bin/monitor-dashboard.sh

# Add to crontab (every 5 minutes)
crontab -e
# Add: */5 * * * * /path/to/trinity-w1/bin/monitor-dashboard.sh
```

## Status Dashboard Features

The status page (`/status.html`) displays:

| Metric | Description | Update Frequency |
|--------|-------------|------------------|
| System Status | Online/Offline indicator | Auto-refresh 30s |

## Troubleshooting

### Issue: Page Not Found (404)

**Cause:** GitHub Pages hasn't propagated yet

**Solution:**
- Wait 1-2 minutes
- Hard refresh: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows/Linux)

### Issue: Styles Not Loading

**Cause:** Asset paths incorrect

**Solution:**
- Check baseUrl configuration in vite.config.ts
- Verify asset paths in index.html

### Issue: Documentation Links Broken

**Cause:** baseUrl misconfiguration in docusaurus.config.ts

**Solution:**
- Ensure `baseUrl: '/trinity/docs/'` in docusaurus.config.ts
- Rebuild: `cd docsite && npm run build`
- Redeploy: `./bin/deploy-gh-pages-quick.sh`
