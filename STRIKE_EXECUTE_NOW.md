### PREREQUISITES
**macOS:**
```bash
brew install yosys nextpnr icestorm
```

**Verify:**
```bash
yosys --version
nextpnr-ice40 --version
icepack --version
```

### STEP 1: Create build directory
```bash
mkdir -p build
```

### STEP 2: Create synth.ys
```bash
cat > synth.ys << 'EOF'
# TRINITY OS Yosys Synthesis Script

read_verilog rtl/fpga/ternary_alu.v
read_verilog rtl/fpga/sacred_opcodes.v
read_verilog rtl/fpga/led_controller.v
read_verilog rtl/fpga/top.v

synth_ice40 -top trinity_top
write_blif build/trinity.blif
stat
show trinity_top
EOF
```

### STEP 3: Run synthesis
```bash
yosys synth.ys
```

### STEP 4: Create constraints.pcf
```bash
cat > constraints.pcf << 'EOF'
# TRINITY OS Pin Constraints
set_io clk_12mhz 35
set_io rst_n 34
set_io led[0] 99
set_io led[1] 98
set_io led[2] 97
set_io led[3] 96
set_io led[4] 95
set_io led[5] 94
set_io led[6] 93
set_io led[7] 92
set_io uart_rx 12
set_io uart_tx 13
EOF
```

### STEP 5: Place & Route
```bash
nextpnr-ice40 --pcf constraints.pcf --asc build/trinity.asc build/trinity.blif
```

### STEP 6: Pack bitstream
```bash
icepack build/trinity.asc build/trinity_os_v1.0.ice
```

### STEP 7: Flash to hardware
```bash
sudo iceprog build/trinity_os_v1.0.ice
```

### STEP 8: Verify LEDs blink
- **LEDs should blink at φ pattern (1.618 Hz)**
- Record video or photo as **HARDWARE PROOF**
