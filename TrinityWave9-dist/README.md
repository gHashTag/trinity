# Trinity Wave 9 — Swift UI

## Структура

```
TrinityWave9/
├── Wave9App.swift          # SwiftUI приложение
└── README.md               # Документация
```

## Как собрать

```bash
# Требуется Xcode 15+
xcodebuild -scheme Wave9App -destination 'platform=macOS,name=Any Mac'
```

## Функции

- **Обзор** — показывает всех устройств и воркеров в одном месте
- **Статус** — детальный статус по каждому устройству (running/stopped/error)
- **Настройки** — S3 MultiObj веса, scheduler, batch size
- **Действия** — запуск/остановка всех устройств или отдельных
- **Логи** — фильтрация по уровню/устройству/типу

## Ключевые особенности

1. **Мак 2 и Мак 3** — в одном приложении
2. **S3 MultiObj настройки** — NTP, JEPA, NCA веса с предетами
3. **Активная иконка** — кнопки для запуска/остановки
4. **Логи в реальном времени** — ScrollView с автоскроллом
5. **Экспорт конфигурации** — возможность сохранить настройки для других машин

## Сравнение с CLI

| Функция | CLI | Swift UI |
|---------|-----|---------|
| Запуск воркеров | `tri farm local-wave9 multi-mac start` | Кнопка «Запустить» |
| Остановка воркеров | `tri farm local-wave9 multi-mac stop` | Кнопка «Остановить» |
| Настройка количества | `--workers-start/ --workers-count` | Текстовое поле + стеpper |
| S3 MultiObj | флаг в CLI | Переключатель в UI |
| Проверка seeds | `multi-mac verify` | Кнопка в UI |

Swift UI рекомендован для:
- Быстрого визуального управления (не терминал)
- Дружественного интерфейса для не-программистов
- Мониторинга в реальном времени

CLI остаётся для:
- Автоматизации (GitHub Actions, CI/CD)
- Развертывания на большее количество Mac
- Скриптования сложных сценариев
