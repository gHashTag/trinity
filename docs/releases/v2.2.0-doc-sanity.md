**Status:** DEFERRED to v2.3.0

Modules without dedicated READMEs:
- `src/needle/` — Semantic search
- `src/firebird/` — LLM engine
- `src/vibeec/` — VIBEE compiler

**Rationale:** These modules have API documentation in source files and are referenced in main docs. Dedicated READMEs are nice-to-have but not essential for v2.2.0 GA.

### 2. Version Numbers

**Status:** ACCEPTED

Version numbers (v2.2.0) are only in release documents. Core documentation uses version-agnostic references.

**Rationale:** Reduces maintenance burden. Version-specific docs live in `docs/releases/`.

### 3. FORGE Documentation

**Status:** ACCEPTED

FORGE has known bugs documented in `CLAUDE.md`. Alternative (openXC7) is clearly specified as the official path.

**Rationale:** Transparent communication of known limitations.
