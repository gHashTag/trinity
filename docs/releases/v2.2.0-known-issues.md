## Detailed Issue Analysis

### 1. vsa-bench / vsa-cached-bench Build Failures

**Status:** ACCEPTED (Non-blocking)

**Error:**
```
error: import of file outside module path
  --> src/needle/vsa.zig:13:29
```

**Impact:** Benchmark tools fail to compile. These are development tools, not production code.

**Workaround:** Use `zig build tri` for core functionality.

**Fix Target:** v2.2.1 post-release

---

### 2. trinity-node Missing Method

**Status:** DEFERRED (Non-blocking)

**Error:**
```
error: no field or member function named 'broadcastStorageAnnounce'
```

**Impact:** `trinity-node` binary (experimental P2P feature) doesn't build.

**Rationale:** This feature is experimental and not part of the v2.2.0 core release.

**Fix Target:** v2.3.0 (when P2P is officially supported)

---

### 3. needle/vsa.zig Import Path

**Status:** DEFERRED (Non-blocking)

**Issue:** Module imports from parent directory outside module path.

**Impact:** Violates FHS (Filesystem Hierarchy Standard) but works in practice.

**Rationale:** Cosmetic issue—doesn't affect functionality at runtime.

**Fix Target:** v2.2.1

---

### 4. FORGE FPGA Synthesis Bugs

**Status:** ACCEPTED (Documented Limitation)

**Known Bugs:**
- IOB placement failures
- OLOGIC configuration missing (ZINV, TFF)
- Net-to-port matching errors

**Impact:** FORGE Zig toolchain not suitable for complex designs.

**Workaround:** Use openXC7 Docker toolchain (official path).

**Documentation:** `CLAUDE.md` contains warnings about FORGE limitations.

**Fix Target:** v2.4.0 (major FORGE refactor)

---

### 5. Large Files (>500 lines)

**Status:** DEFERRED (Technical Debt)

**Files:**
- `uart_host_v5_refactored.zig` (~700 lines)
- `uart_host_v6_refactored.zig` (~600 lines)
- `src/common/errors.zig` (~240 lines — acceptable)

**Impact:** Code organization, not functionality.

**Rationale:** Refactoring completed in Sprint 2 reduced duplication. Further splitting is cosmetic.

**Fix Target:** v2.3.0

---

### 6. Incomplete Test Coverage

**Status:** DEFERRED (Tech Debt)

**Coverage:**
- VSA core: 99.5% ✅
- UART protocol: 100% ✅
- Consciousness: 90% ✅
- Some edge cases in utility modules: &lt;50%

**Impact:** Low probability of bugs in untested utility paths.

**Rationale:** Critical hot paths are fully tested. Utilities are simple and well-understood.

**Fix Target:** Ongoing (v2.2.x)
