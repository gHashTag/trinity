SIMD Bind Algorithm

HYBRIDBIGINT_BIND_SIMD(a, b)
// ARM64 NEON: 32 limbs × 16 trits parallel
const result = createVector();
// Load a, b into NEON registers (128-bit)
va = loadNEON(a.limbs); // 32×u32 → v4×u32
vb = loadNEON(b.limbs);
// XOR each limb (ternary multiplication)
for i = 0; i < 32; i++ {
result.limbs[i] = va[i] ^ vb[i]; // XOR = ⊗ (bind)
}
return result;

Theorem: Ternary Majority Vote

The bundle operation for balanced ternary {-1, 0, +1} implements ternary majority voting: if two or more inputs agree, output the agreeing value; otherwise output 0.

bundle(a,b,c) =
IF count(-1) ≥ 2 THEN -1
ELSE IF count(+1) ≥ 2 THEN +1
ELSE 0

(Generalizes to n inputs)
