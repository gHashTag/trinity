Linear Type Checking Algorithm

CHECK_LINEAR_TYPE(expr, env)
function CHECK_LINEAR_TYPE(expr, env)
for each variable v in expr do
mode ← GET_MODE(v, env)
usage_count ← COUNT_USAGE(expr, v)
if mode = SINK then
if usage_count ≠ 1 then
error(Sink value must be used exactly once)
end if
end if
if mode = INOUT then
if usage_count > 1 then
error(Inout value has single reference)
end if
end if
end for
return OK
end function

Mathematical Foundation

Theorem: Linear Type Memory Safety

In a linear type system with Let/Inout/Sink/Set modes, every value is either (a) immutable and copyable (Let), (b) mutable with single ownership (Inout), (c) consumed exactly once (Sink), or (d) shared and readable (Set). This classification ensures that:

1. No value is accessed after being consumed (Sink)
2. No mutable value has multiple owners (Inout)
3. All resources are properly released (RAII)

∴ Memory leaks are impossible by construction
∎ QED
