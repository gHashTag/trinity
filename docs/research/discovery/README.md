## Template for New Discoveries

Each discovery file should follow `../DEFENSIVE_PUB_TEMPLATE.md`:

```bash
cp ../DEFENSIVE_PUB_TEMPLATE.md discovery/p{N}_{name}.md
```

Fill in all required sections:
1. Abstract (150-250 words)
2. Problem Statement
3. Background and Known Solutions
4. Novelty Statement
5. Implementation (with code examples)
6. Embodiments / Examples (3+)
7. Supporting Figures
8. Experimental Results
9. Comparison with Related Work
10. References
11. Cross-References
12. How to Cite
13. Revision History

## Zenodo Upload Script

```bash
# Create bundle release
zenodo_create_bundle() {
    local bundle=$1
    local title=$2

    # Create tarball
    tar czf ${bundle}.tar.gz \
        discovery/*.md \
        citation/${bundle}.cff \
        ../PRIOR_ART_NETWORK.md

    # Upload to Zenodo (requires zenodopy)
    zenodopy upload ${bundle}.tar.gz \
        --title "${title}" \
        --authors "Trinity Project" \
        --license "CC-BY-4.0"
}
```
