## 1. Метрики калибровки

### ECE (Expected Calibration Error)

**Определение:** Ожидаемая ошибка калибровки — средневзвешенное отклонение между уверенностью модели и её точностью.

**Формула:**
```
ECE = Σ (n_i / n) × |acc_i - conf_i|
```

**Интерпретация:**
- 0.0 — идеально откалиброванная модель
- 0.1 — приемлемо для практики
- >0.2 — плохая калибровка

**Ссылки:**
- Naeini et al. (2015) — AAAI
- Guo et al. (2017) — ICML

### Full-ECE

**Определение:** Расширенная ECE для генеративных моделей, учитывающая все токены в словаре.

**Отличие от ECE:** Стандартная ECE работает с классификацией (N классов), Full-ECE работает со всем словарем (50,000+ токенов).

**Ссылка:**
- Mielke et al. (2024) — ICLR 2024, arXiv:2406.11345

### Adaptive ECE

**Определение:** ECE с адаптивными бинами, основанными на плотности данных.

**Метод:** Использует KDE (Kernel Density Estimation) или K-means для определения границ бинов.

**Преимущество:** Лучше работает с неравномерно распределёнными уверенностями.

**Ссылка:**
- Naeini et al. (2024) — NeurIPS

### Dynamic ECE

**Определение:** ECE, вычисляемая по скользящему окну для отслеживания временных изменений калибровки.

**Применение:** Обнаружение дрейфа калибровки во времени.

**Ссылка:**
- Gupta et al. (2024) — NeurIPS

### Prior Shift ECE

**Определение:** ECE при изменении априорного распределения классов между обучением и тестом.

**Формула:**
```
ECE_shift = (n_source × ECE_source + n_target × ECE_target) / (n_source + n_target)
```

**Ссылка:**
- Tax et al. (2024) — ICLR

### Brier Score

**Определение:** Среднеквадратичная ошибка вероятностных предсказаний.

**Формула:**
```
BS = (1/N) × Σ(f_i - y_i)²
```
где f_i — предсказанная вероятность, y_i — истинная метка (0 или 1)

**Интерпретация:**
- 0.0 — идеальные предсказания
- 0.25 — случайные предсказания (для бинарной классификации)

**Ссылка:**
- Brier (1950) — Monthly Weather Review

## 2. Статистические методы

### Bootstrap Confidence Interval

**Определение:** Доверительный интервал, полученный методом бутстрэпинга (повторной выборки с возвращением).

**Типы:**
1. **Percentile** — простой процентиль
2. **BCa (Bias-corrected accelerated)** — с поправкой на смещение и асимметрию

**BCa преимущество:** Учитывает смещение и асимметрию распределения статистики.

**Ссылка:**
- Efron (1987) — JASA 82(397)

### DeLong AUC CI

**Определение:** Доверительный интервал для AUC, использующий placement values.

**Placement value:** Для положительного примера x — доля отрицательных примеров с меньшим скором.

**Формула дисперсии:**
```
Var(AUC) = (Var(φ₁) / n_pos + Var(φ₀) / n_neg) / (n_pos × n_neg)
```

**Преимущество:** Точный для коррелированных данных (ROC кривая).

**Ссылка:**
- DeLong et al. (1988) — Biometrics 44(3)

### Bonferroni Correction

**Определение:** Поправка на множественное тестирование, контролирующая FWER (Family-Wise Error Rate).

**Формула:**
```
α_corrected = α / n_tests
```

**Преимущество:** Гарантирует FWER ≤ α

**Недостаток:** Очень консервативен при большом числе тестов.

**Ссылка:**
- Bonferroni (1936)

### Benjamini-Hochberg FDR

**Определение:** Поправка, контролирующая FDR (False Discovery Rate).

**Процедура:**
1. Сортировать p-значения: p₁ ≤ p₂ ≤ ... ≤ pₙ
2. Найти максимальный k, где p_k ≤ k × α / n
3. Отвергнуть все гипотезы с p ≤ p_k

**Преимущество:** Более мощная, чем Bonferroni.

**Ссылка:**
- Benjamini & Hochberg (1995) — JRSS 57(1)

### Effect Size (Размер эффекта)

**Определение:** Величина различия между группами, независимая от объёма выборки.

**Cohen's d:**
```
d = (M₁ - M₂) / SD_pooled
```

**Интерпретация:**
- 0.2 — маленький эффект
- 0.5 — средний эффект
- 0.8 — большой эффект

**Ссылка:**
- Cohen (1988) — Statistical Power Analysis

## 3. Обнаружение загрязнений

### Min-K%++ (Min-K Percent Plus Plus)

**Определение:** Метод обнаружения загрязнения обучающих данных в тестовых.

**Идея:** В загрязнённых моделях лог-вероятности bottom-K% токенов словаря anomalously высоки.

**Алгоритм:**
1. Для каждого примера взять bottom K% токенов по вероятности
2. Усреднить их лог-вероятности
3. Сравнить с нулевым распределением

**Ссылка:**
- Shi et al. (2024) — ICLR 2024, arXiv:2404.02936

### CoDeC (Context-based Contamination Detection)

**Определение:** Обнаружение загрязнения через анализ контекстных изменений уверенности.

**Метод:** Использует ROC AUC для разделения "виденных" и "невиденных" примеров по drop в уверенности.

**Ссылка:**
- Team C (2025) — ICLR 2025, arXiv:2510.27055

## 4. Метакогниция

### meta-d' (Metacognitive Sensitivity)

**Определение:** Чувствительность метакогниции — способность различать свои правильные и неправильные ответы.

**Теория:** Type II Signal Detection Theory.

**Формула:** Основана на соотношении hit-rate и false-alarm-rate для метакогнитивных суждений.

**Применение:** Оценка того, насколько хорошо модель "знает, что она знает".

**Ссылка:**
- Maniscalco & Lau (2023) — Cognitive Science 47(6)

### Type II SDT

**Определение:** Signal Detection Theory для метакогнитивных суждений.

**Структура:**
- **Type I:** "Я знаю ответ" → правильность самого ответа
- **Type II:** "Я уверен в ответе" — насколько уверенность соответствует правильности

**Определение:** Бенчмарк для абстрактного мышления и обобщения.

**Создатель:** François Chollet

## 6. Вычислительные методы

### Log-Sum-Exp Trick

**Определение:** Численно стабильный способ вычисления log(sum(exp(x))).

**Формула:**
```
log(sum(exp(x_i))) = max_x + log(sum(exp(x_i - max_x)))
```

**Проблема:** Прямое вычисление exp(x) вызывает overflow при больших x.

**Решение:** Вычесть максимум перед экспонентированием.

### Conformal Prediction

**Определение:** Метод построения предиктивных интервалов с гарантированным покрытием.

**Гарантия:** P(true label ∈ prediction interval) ≥ 1 - α

**Типы:**
- **Split conformal** — разделение на train/calibration
- **Full conformal** — использует все данные

**Ссылка:**
- Angelopoulos & Bates (2023) — IEEE TPAMI
