## Best Practices

### 1. Use 5-Sentence Enhanced Abstract
- First sentence: Motivation (why is this research important)
- Second sentence: Core contribution (what did you do differently)
- Third sentence: Mathematical foundation (φ² + 1/φ² = 3, etc.)
- Fourth sentence: Methods summary (ternary quantization, etc.)
- Fifth sentence: Key results (numbers with % improvement)
- Sixth sentence: Significance (why this matters)

### 2. FAIR Principles (15/15)
All templates follow FAIR principles:
- **Findable**: Descriptive title (≤100 chars)
- **Accessible**: Fulltext download + persistent identifier
- **Interoperable**: Standard formats (CSV, BibTeX)
- **Reusable**: CC-BY-4.0 license
- **Identified**: Persistent DOI with versioned citation (v5.0, v6.0, etc.)

### 3. Scientific Accuracy
- Cite relevant peer-reviewed work
- Provide exact numbers (not "X-Y% improvement")
- Document all assumptions

### 4. Trinity-Specific Patterns
- Include φ values with 3+ significant digits
- Reference trinity identity: φ² + 1/φ² = 3
- Use sacred mathematical symbols (φ, φ⁻¹, φ⁻³)
