## Upload Procedure

### Step 1: Create Parent Collection
1. Go to https://zenodo.org/deposit
2. Click "New upload"
3. Upload parent collection files
4. Enter metadata (use template above)
5. **Save as draft** (do not publish yet)

### Step 2: Create Each Bundle
1. For each B001-B007:
   - Create new upload
   - Upload bundle description + CITATION file
   - Enter metadata
   - Add "Is part of" relation to parent DOI
   - Publish individually

### Step 3: Link and Publish Parent
1. Go to parent collection draft
2. Add "Has part" relations to all bundles
3. Verify all links
4. Publish parent collection

### Step 4: Post-Upload
1. Verify all DOIs are resolvable
2. Test all DOI links
3. Create GitHub release
4. Announce publication
