## Scientific Documentation Standards

### 1. Metadata Requirements

Each Zenodo upload MUST include:

| Field | Requirement | Example |
|-------|-------------|---------|
| **Title** | Descriptive, includes version | "Trinity B001: Ternary Neural Networks — Complete Scientific Framework v2.0" |
| **Authors** | Full name, affiliation, ORCID | "Vasilev, Dmitrii" |
| **Description** | Abstract + Methods + Results | 500-1000 words minimum |
| **Keywords** | 5-10 relevant terms | "ternary, neural networks, FPGA, HSLM, phi" |
| **License** | CC-BY-4.0 recommended | CC-BY-4.0 |
| **DOI** | Auto-generated by Zenodo | 10.5281/zenodo.XXXXXX |

### 2. File Structure

```
bundle_name vX.X/
├── README.md (main description)
├── CITATION.cff (citation metadata)
├── AUTHORS.md (contributor list)
├── LICENSE (CC-BY-4.0)
├── docs/
│   ├── methods.md (detailed methods)
│   ├── results.md (tables, figures)
│   └── reproducibility.md (how to reproduce)
├── code/ (source code with version tags)
└── data/ (datasets, if applicable)
```

### 3. Quality Checklist

Before publishing to Zenodo:

- [ ] Abstract ≤ 250 words
- [ ] All methods described in detail
- [ ] All results with error bars/confidence intervals
- [ ] Code compiles and tests pass
- [ ] CITATION.cff included
- [ ] LICENSE file included
- [ ] DOI linked to Git tag
- [ ] Keywords ≤ 10
- [ ] References formatted consistently
- [ ] Reproducibility instructions tested
