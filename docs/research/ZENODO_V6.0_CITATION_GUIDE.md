## Citation Best Practices

### DO

1. **Always include the DOI** — enables permanent linking
2. **Specify the version** — v6.0 for reproducibility
3. **Include the license** — CC-BY-4.0 or MIT as appropriate
4. **Cite specific bundles** — when using specific components
5. **Use ORCID** — when available (to be updated)

### DON'T

1. **Don't cite v5.2 DOIs for v6.0** — version mismatch
2. **Don't omit the version number** — reproducibility issue
3. **Don't use GitHub URLs** — prefer DOI for permanence
4. **Don't forget to update ORCID** — replace placeholder
