## TRI-27 Phase: Codegen, Not Hand-Written

**DO NOT commit hand-written .t27 files** - they violate ISA and won't assemble.

Instead, build `emit_t27` (VIBEE → .t27 codegen) that generates correct assembly from specs:

```
specs/depin/neuroanatomy.tri → emit_t27 → src/tri27/depin/*.t27 → assemble → .tbin
```

### emit_t27 Requirements

1. **Verified ISA Subset** - Only use opcodes from `src/tri27/emu/decoder.zig`
2. **No register-indirect addressing** - Use `LD dst, addr16` with pre-computed address
3. **No PUSH/POP** - Use `CALL`/`RET` for subroutine linkage
4. **Multi-word arithmetic** - For values > 2.1×10⁹ (i32 max)
5. **Single-file output** - No cross-file CALL without linker

Study `src/tri27/reticular_raphe.t27` for correct TRI-27 assembly patterns.

## Assembly Format (.t27)

```assembly
# Comments start with #
.const
    WINDOW_SIZE = 20
    PHI_DECAY = 65535  # Q16 fixed-point

.data
    .dword 0 0 0 0     # Initialized data

.code
    LDI t0, 0          # Load immediate into register t0
    ADD t1, t0, t2     # t1 = t0 + t2
    JLT t5, t6, loop   # Jump if t5 < t6
    HALT               # Stop execution
```

---

## Key Opcodes

| Opcode | Description |
|--------|-------------|
| `LDI dst, imm` | Load immediate |
| `MOV dst, src` | Copy register |
| `ADD dst, src1, src2` | Addition |
| `MUL dst, src1, src2` | Multiplication |
| `DIV dst, src1, src2` | Division |
| `JLT src1, src2, label` | Jump if src1 < src2 |
| `JGT src1, src2, label` | Jump if src1 > src2 |
| `JZ src, label` | Jump if src == 0 |
| `JNZ src, label` | Jump if src != 0 |
| `JMP label` | Unconditional jump |
| `HALT` | Stop execution |
| `PHI_CONST dst` | Load φ (1.618...) |
| `DOT dst, v1, v2` | VSA dot product |
